# Wavo Build 38 App Icon

The iOS App Store build uses a single finalized Wavo app icon:

- 1024 × 1024 RGB PNG
- blue left-to-right gradient background
- black Wavo lightning mark
- no transparency
- no bundled alternate App Store icon assets

The native iOS Premium UI hides the alternate app-icon selector because those cosmetic alternate assets are intentionally not shipped in the App Store build.
